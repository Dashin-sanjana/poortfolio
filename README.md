# Dashin Sanjana — iOS Developer Portfolio

A cinematic, responsive personal portfolio built with Next.js, React, GSAP, and Three.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verify

```bash
npm run typecheck
npm run build
```

The hero portrait is the original image provided by Dashin. The project cards distinguish active products, professional work, research, and learning projects; missing iOS demos are labelled as pending assets.
